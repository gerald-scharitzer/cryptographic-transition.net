# Trust-Based Systems

enable our society and economy.

Trust represents predictability.
When a system behaves as we predict, then there is reasonable trust in predicting some part of the future.
When we control some part of a system, such that we change the predictions and they still manifest reliably,
then there is reasonable trust in shaping the future.

We trust in entities to behave as we predict.
For that we trust the identities of these entities.

We link identities to public keys and the holders of the private keys.
